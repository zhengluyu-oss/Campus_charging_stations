## Why

校园充电桩项目将作为毕业设计与面试 Demo，并计划部署到服务器。现有前端虽已完成一轮「清爽化」，但第一眼冲击力不足，难以在答辩投影与面试演示中形成「智能能源产品」印象。需要一套可上线、可降级的沉浸式 UI（方案 C），在用户端与管理端统一「科技能源感」品牌，同时覆盖电影感动效、轻氛围层与数据可视化。

## What Changes

- 建立 **Campus Energy** 设计系统：深空背景 + 电光青绿 Token、展示/正文字体、玻璃面板与能量态色彩语义。
- 在 `frontend` 与 `admin-frontend` 落地 **全站沉浸式皮肤**（鸿蒙端不在本次范围）。
- 引入 **动效体系 A**：路由转场、错落入场、KPI/SOC 数字滚动、充电光带等；尊重 `prefers-reduced-motion`。
- 引入 **氛围层 B**：App 根级单例 Canvas/轻 WebGL 氛围；按路由强度预设；设置项与设备自动降级（`off | low | full`）。
- 引入 **可视化 C**：统一暗色能源图表主题；用户端地图热力/充电曲线等；管理端仪表盘 KPI 与趋势大屏。
- 按 **L3/L2/L1** 页面分级铺开表现力；优先打满演示主路径与管理仪表盘，再铺其余业务页。
- **移除/替换**残留的重型手势追踪与不可控常驻重粒子方案，改为可控氛围运行时（避免 Demo 与生产翻车）。
- 不改后端 API 契约；业务逻辑与路由结构尽量保留，主要改壳层、主题、组件皮肤与可视化呈现。

## Capabilities

### New Capabilities

- `campus-energy-theme`: 全局设计 Token、字体、Glass/能量 UI 基础组件与两端主题对齐。
- `effects-runtime`: 特效等级、设备/无障碍探测、单例氛围层、按路由强度与可销毁策略。
- `cinematic-motion`: 页面入场、路由转场、数字滚动、充电能量进度等动效约定。
- `energy-data-viz`: ECharts（或现有图表库）能源主题与可复用图表组件（趋势、环图、热力条、仪表盘栅格等）。
- `user-immersive-pages`: 用户端各页 L3/L2/L1 沉浸编排（欢迎/地图/充电监控优先）。
- `admin-command-pages`: 管理端指挥舱风格编排（仪表盘 L3，业务管理 L2/L1）。

### Modified Capabilities

- （无）当前 `openspec/specs/` 下无既有能力规格；本次全部为新建。

## Impact

- **代码**：`frontend/`、`admin-frontend/` 的样式、布局壳、共享 UI、图表与特效相关组件；可能调整 `App.vue`、路由视图包装、设置页。
- **API**：无后端接口变更；图表与地图数据仍走现有接口，缺数时展示科技感空态。
- **依赖**：可能新增/调整字体、ECharts（若未引入）、轻量动效工具；氛围优先 2D Canvas，仅关键 L3 页评估轻量 3D；移除不可控的 MediaPipe 手势依赖（若仍存在）。
- **运维/部署**：需验证弱网与低配设备降级；生产构建对氛围与重图表异步分包；提供特效开关便于服务器环境排障。
- **范围外**：`harmonyos/`、后端业务规则、数据库结构。
