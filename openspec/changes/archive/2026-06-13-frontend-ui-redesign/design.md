## Context

前端项目使用 Vue 3 + Element Plus，当前设计风格不统一：欢迎页/登录页是深色科技风，仪表板是浅色简约风。需要统一为深色科技主题，提升整体视觉体验。

## Goals / Non-Goals

**Goals:**
- 统一深色科技主题
- 提升 Header/Footer 设计感
- 优化卡片交互效果
- 保持与 Element Plus 组件的协调

**Non-Goals:**
- 不更换 UI 框架
- 不修改业务逻辑
- 不添加新的页面

## Decisions

### 1. 统一深色主题

**决定**: 所有页面统一使用深色渐变背景（#0f2027 → #203a43 → #2c5364）

**原因**: 欢迎页和登录页已经使用这个配色，效果很好，将这个风格扩展到所有页面。

### 2. 毛玻璃 Header

**决定**: Header 使用 `backdrop-filter: blur(12px)` + 半透明背景

**原因**: 与整体深色主题协调，同时保持内容可读性。

### 3. 渐变卡片

**决定**: 卡片使用渐变边框和悬停发光效果

**原因**: 增强视觉层次感，提升交互反馈。

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|---------|
| 深色主题可能影响可读性 | 使用足够对比度的白色文字 |
| Element Plus 组件默认浅色 | 使用 CSS 变量覆盖主题色 |
