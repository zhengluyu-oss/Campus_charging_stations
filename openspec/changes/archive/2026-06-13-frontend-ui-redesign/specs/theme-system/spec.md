## ADDED Requirements

### Requirement: Unified dark tech theme
The system SHALL use a consistent dark gradient background across all pages.

#### Scenario: All pages background
- **WHEN** user visits any page
- **THEN** the background SHALL use dark gradient (primary: #0f2027 → #203a43 → #2c5364)

### Requirement: Modern glassmorphism header
The header SHALL use glassmorphism style with backdrop blur.

#### Scenario: Header appearance
- **WHEN** user sees the header
- **THEN** it SHALL have semi-transparent background with backdrop-filter blur effect

### Requirement: Animated card interactions
Dashboard cards SHALL have smooth hover animations.

#### Scenario: Card hover
- **WHEN** user hovers over a dashboard card
- **THEN** the card SHALL lift up with shadow and subtle glow effect

### Requirement: Consistent color palette
All pages SHALL use the same color palette.

#### Scenario: Color usage
- **WHEN** any element uses color
- **THEN** it SHALL use colors from the defined palette (cyan: #00c9ff, green: #92fe9d, white: #ffffff)
