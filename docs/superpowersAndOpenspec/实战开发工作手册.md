## 技能触发方式速查

| 类型 | 说明 |
|------|------|
| **Superpowers 技能** | AI 根据意图自动调用，你只需描述目标 |
| **OpenSpec 技能** | 你输入斜杠命令显式触发 |

| 命令 | 作用 |
|------|------|
| `/opsx:explore [变更名]` | 进入只读探索模式 |
| `/opsx:propose <序号>-<变更名>` | 创建变更账本（proposal + tasks） |
| `/opsx:apply <序号>-<变更名>` | 执行 tasks.md 任务清单（轻量路径） |
| `/opsx:archive <序号>-<变更名>` | 归档已完成的变更 |
